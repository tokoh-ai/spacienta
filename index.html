How this score works

100-point comparative score: Accessible Routes 30 · Target Approach 20 · Entrance Access 20 · Reachable Maneuvering 20 · Fixed Feature Access 10.

0.92 m route reference 0.82 m door opening reference 1.52 m circular turning reference 1.20 m route comfort target

The first three dimensions are rounded metric accessibility reference values. The 1.20 m path target is a Spacienta comfort heuristic used to compare layouts. Required routes originate at one primary entrance and terminate in modeled furniture access zones. Optional fixed-feature categories are N/A when absent; rooms without accessibility targets are not rated. Physical overlaps are treated as invalid conditions rather than bonus points. Door swing/handedness and jurisdiction-specific code checks are not modeled.
